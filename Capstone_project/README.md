ONLINE LEARNING PLATFORM – CAPSTONE PROJECT

This project is a responsive online learning website built using HTML5 and CSS3. It follows the structure required in the capstone instructions and matches the sample UI design.

FEATURES INCLUDED

Fully Semantic HTML5 Structure

header, nav, main, section, footer
Clean, organized layout
Responsive Layout

Flexbox and Grid
Works on desktop, tablet, and mobile
Modern UI Components

Navigation bar with logo, search bar, Login and Sign Up buttons
Hero section with heading, subtitle, search bar and button
Popular Categories section with icon cards
Featured Courses section with sample course cards
Filters: Level, Price, Certificate option
Footer
PROJECT STRUCTURE

index.html style.css images/ dev.png design.png business.png language.png academics.png music.png lifestyle.png science.png course1.jpg course2.jpg course3.jpg

IMAGES REQUIRED

All icons and course images must be stored inside the "images" folder.

Category Icons: dev.png design.png business.png language.png academics.png music.png lifestyle.png science.png

Course Thumbnails: course1.jpg course2.jpg course3.jpg

HOW TO RUN

Place index.html and style.css in the same folder.
Create a folder named "images" and place all required images inside it.
Open index.html in any web browser.

TECHNOLOGIES USED

HTML5
CSS3
Flexbox
CSS Grid
No JavaScript required

LEARNING OUTCOMES

Built a clean, modern, responsive webpage
Used semantic HTML tags
Created a professional layout
Used Grid and Flexbox properly
Added a functional contact form and navigation
Improved spacing, hierarchy, and UI design
